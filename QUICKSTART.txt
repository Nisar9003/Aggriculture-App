🚀 INSTANT SETUP (3 Steps)

1. ADD API KEYS
   Edit .env file and add:
   - EXPO_PUBLIC_OPENWEATHER_API_KEY=your_key
   - EXPO_PUBLIC_OPENAI_API_KEY=your_key

2. INSTALL DEPENDENCIES
   npm install

3. START DEVELOPMENT
   npm run dev
   Visit: http://localhost:8081

🌐 DEPLOYMENT (Pick One)

VERCEL (Easiest):
1. git push origin main
2. Visit vercel.com
3. Connect your repo
4. Set environment variables
5. Deploy automatically

NETLIFY:
1. npm install -g netlify-cli
2. netlify deploy --prod --dir=dist

DOCKER (Self-hosted):
1. docker build -t haray-khet .
2. docker run -p 3000:3000 \
     -e EXPO_PUBLIC_SUPABASE_URL=... \
     -e EXPO_PUBLIC_OPENWEATHER_API_KEY=... \
     -e EXPO_PUBLIC_OPENAI_API_KEY=... \
     haray-khet

🐛 TROUBLESHOOTING

App won't start?
  rm -rf node_modules
  npm cache clean --force
  npm install
  npm run build

API errors?
  1. Check .env file
  2. Verify keys are correct
  3. Check browser console
  4. Try fallback mode (advisor)

Database issues?
  1. Verify Supabase connection
  2. Check RLS policies
  3. Verify user is logged in
  4. Check auth status

Weather not working?
  1. Verify OpenWeather key
  2. Check rate limits
  3. Fallback system still works
  4. Works offline
